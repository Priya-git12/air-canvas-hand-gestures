# 🖐️ Air Canvas using Hand Gestures

Draw on your screen using just your hand — no mouse needed.

This project uses computer vision to track your hand and convert finger movements into drawing actions in real-time.

---

## 🚀 Features

* Draw with index finger
* Color selection using gestures
* Dynamic brush thickness
* Smooth drawing experience
* Clear canvas option

---

## 🛠️ Tech Stack

* Python
* OpenCV
* MediaPipe
* NumPy

---

## 📂 Files

* `handges.py` → main code
* `requirements.txt` → dependencies

---

## ⚙️ How to Run

1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python handges.py

---

## 🎮 Controls

* Q → Quit
* C → Clear screen
